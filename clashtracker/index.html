Sobre os cálculos

Os níveis de referência são consultados no projeto comunitário clash-of-clans-data. A atualização desta base requer internet.

O jogo não fornece níveis de construções, muros, armadilhas nem o momento exato de conclusão das melhorias pela API de jogadores. Nenhuma dessas informações é presumida.

Projeto independente, não oficial e não afiliado à Supercell. Dados de referência: clash-of-clans-data (MIT) · Proxy: RoyaleAPI.
